## Codebase Patterns
- FileSystem: Use `expo-file-system` modern API (`Paths`, `File`, `Directory`) as legacy API is deprecated/runtime-throwing.
- Web support requires `react-dom` and `react-native-web` for browser verification.
- Animations: Reanimated requires `babel.config.js` plugin, `babel-preset-expo`, and `GestureHandlerRootView` wrapping.
