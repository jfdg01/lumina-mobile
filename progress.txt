## Codebase Patterns
- FileSystem: Use `expo-file-system` modern API (`Paths`, `File`, `Directory`) as legacy API is deprecated/runtime-throwing.
- Web support requires `react-dom` and `react-native-web` for browser verification.
- Animations: Reanimated requires `babel.config.js` plugin, `babel-preset-expo`, and `GestureHandlerRootView` wrapping.
- Persistence: Use `@react-native-async-storage/async-storage` for simple key-value storage (works on web and native).
- Reanimated worklets: Use `runOnJS(fn)()` to call JS functions from gesture handler callbacks.
- Wake Lock: Use `expo-keep-awake` with `activateKeepAwakeAsync`/`deactivateKeepAwake`. Always cleanup on unmount.
- Global Gestures: Wrap the parent container (not the target element) with `GestureDetector` to capture gestures anywhere on screen.
- Layout Stability: Use `absolute` positioning for workspaces that must remain static while UI overlays toggle on/off. Avoid flex-based layout shifts.
- Storage Structure: For simple lists, use a "Collection" key (JSON object map) + "Current ID" key pattern. Avoid separate keys per item unless necessary for performance.
- App Structure: `src` is the root for source. `global.css` in `src`. `@` alias maps to `./src`.
- Components: All components in `src/components`. Gluestack UI in `src/components/ui`.
- Image Handling: Use Gluestack `Image` with `source` prop. For local images, `uri` works. `Image` component needs `size` (e.g., `2xl` or `none` + `className` for custom dimensions).
- Storage: Use `StorageService` for all persistent operations to keep stores focused on runtime state.
- Types: Centralize shared interfaces in `src/types/` to prevent circular dependencies.
- Flat Design: Use `rounded-none`, solid backgrounds, and high-contrast uppercase typography (`font-black`, `uppercase`) for a crisp aesthetic.
- Feature Organization: Group related components in subdirectories (e.g., `src/components/projects/`) with an `index.tsx` entry point.
- App Shell Navigation: Use a `renderContent` helper function in `App.tsx` to manage mutually exclusive views (List, Importer, Workspace) for better readability.
- NativeWind: Use `contentContainerClassName` for ScrollView/FlatList content styling instead of `contentContainerStyle`.
- NativeWind: `className` works on `Animated.View` (Reanimated) for static styles; keep `style` strictly for SharedValue animations.
- Mode State: Use positive boolean names (e.g., `isEditMode`) over negated/inverted ones (e.g., `isProjectionMode`). Easier to reason about.
